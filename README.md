## Phases

Each issue follows the same four-phase workflow.

**Phase I — Discovery & Reproduction**  
Choose and understand the issue: why you picked it, what is broken or missing, and how to reproduce it locally (environment setup, steps, evidence).

**Phase II — Solution Planning**  
Analyze the root cause and outline your fix using the UMPIRE framework: understand, match existing patterns, plan implementation, and define how you will review and evaluate the change.

**Phase III — Build & Test**  
Implement the solution, document weekly progress and code changes, and verify the fix with unit tests, integration tests, and manual testing.

**Phase IV — Ship & Reflect**  
Open a pull request, respond to maintainer feedback, and reflect on what you learned, challenges you overcame, and resources that helped.
